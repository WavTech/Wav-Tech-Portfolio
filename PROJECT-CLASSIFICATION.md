# Project Classification Guide

This portfolio documents work completed under the Wav Tech umbrella across different types of engagements. A project appearing in this repository does **not** automatically mean it was a paid commercial engagement.

## Paid Client Work

Work completed for compensation. Earned income from paid Wav Tech work is reported accordingly.

When a public project page does not explicitly state that an engagement was paid, readers should not assume compensation.

## Exposure / Portfolio Projects

Projects completed to gain practical experience, demonstrate technical capability, build professional relationships, create portfolio material, or solve a real-world problem without necessarily being compensated.

These projects may still involve real users, real equipment, and real deliverables.

## Internal Projects

Self-directed projects created under Wav Tech for technical development, experimentation, business infrastructure, or portfolio development.

Examples include the Network+ Practice Lab and Wav-branded web projects.

## Confidential Client Projects

Projects performed for a client where the client identity or project details are intentionally withheld.

Public descriptions may explain the technical scope at a high level while excluding proprietary concepts, private assets, credentials, or identifying information.

## Professional / Employer Experience

Work completed as part of employment with another company is **not represented as Wav Tech client work** in this repository.

Professional experience may inform the technical skills used in independent projects, but employer-owned projects, documentation, network information, credentials, and proprietary materials are intentionally excluded.

## Portfolio Accuracy

The purpose of this repository is to document practical technical experience accurately while respecting client privacy and clearly distinguishing different project types.
