# Custom PC Build Consulting

## Overview

Wav Tech has provided custom PC build consulting for **5 clients**, helping users choose components and plan systems around budget, performance goals, compatibility, and upgradeability.

## Typical Consulting Scope

- Define intended workload and budget
- Select compatible CPU, motherboard, memory, storage, GPU, cooling, and power components
- Review physical case compatibility
- Check power-supply headroom
- Evaluate cooling requirements
- Compare upgrade paths
- Recommend cost-effective performance improvements
- Review parts before purchase
- Provide build and setup guidance

## Example Technical Areas

- AMD Ryzen platforms
- Radeon graphics
- DDR4 memory
- SATA and solid-state storage
- ATX motherboards and cases
- Power-supply sizing
- Air and AIO liquid cooling
- BIOS/UEFI configuration
- Windows and driver setup

## Performance Upgrade Consulting

Wav Tech also evaluates existing PCs to determine whether targeted upgrades provide better value than replacing the entire system.

Common recommendations include:

- SSD upgrades
- Memory expansion
- GPU upgrades
- Storage expansion
- Cooling improvements
- CPU/platform upgrades
- Windows optimization
