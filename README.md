The work documented here spans end-user support, computer repair, custom PC consulting, residential networking, compact home infrastructure, domain and email configuration, web development, application design, studio technology, and selected digital projects.

> **Portfolio note:** Not every project shown here was a paid engagement. Wav Tech has completed a combination of paid client work, exposure/portfolio projects, and internal projects. Compensation is not implied unless explicitly stated. Earned income from paid work is reported accordingly.

## Internal Technical Project — Network+ Practice Lab

A self-directed web application created to turn a large CompTIA Network+ question bank into an interactive study and testing platform.

Features developed across the project include:

- Multiple question banks
- Study and exam modes
- Immediate answer feedback
- Review functionality
- Topic breakdowns
- Score and progress tracking
- User authentication
- Persistent progress
- Supabase integration
- GitHub-based deployment

This project demonstrates iterative application development, troubleshooting, data organization, authentication, and deployment skills.
